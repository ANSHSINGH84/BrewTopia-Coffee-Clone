☕ BrewTopia – Coffee Shop Website Clone

BrewTopia is a responsive coffee shop website clone built using HTML, CSS, and JavaScript. This project focuses on creating a modern, visually appealing UI with smooth animations and interactive elements inspired by real-world café websites.


🛠 Tech Stack

HTML5 – Structure and semantic layout

CSS3 – Styling, Flexbox, animations, and responsiveness

JavaScript – Interactivity and dynamic behavior

✨ Features

Responsive design for desktop, tablet, and mobile

Modern coffee shop UI

Smooth hover effects and animations

Interactive navigation and sections

Clean and minimal layout

📂 Project Purpose

This project was created to:

Practice front-end development fundamentals

Improve UI/UX design skills

Build a portfolio-ready project using core web technologies
